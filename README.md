# Yandex Browser Blocker: Active protection

## Install libs

```go mod tidy```

## Compile

For Common (Without console) Program:
```go build -ldflags="-H windowsgui"```
Flag `-ldflags="-H windowsgui"` allows you to hide the console

For Debug (With console) Program:
```go build```
